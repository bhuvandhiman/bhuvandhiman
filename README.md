## A project I'm proud of

### Recall. — DSA Practice Tracker

Solving hundreds of DSA problems is useful, but it's easy to lose track of what you're actually good at.

Recall records the problems you solve, the pattern you used, and how you reached the solution — independently, with a hint, or after seeing the solution.

The dashboard ranks your performance across different DSA patterns and highlights the ones you're struggling with, so instead of blindly solving more problems, you know what to work on next.
